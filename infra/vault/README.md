# infra/vault

Kelajakda maxfiy ma'lumotlarni (JWT kalitlari, Payme/Click, SMS provayder kalitlari) saqlash uchun HashiCorp Vault konfiguratsiyasi shu yerga qo'yiladi.

Etap 1 da Vault konteyneri ishga tushirilmaydi — maxfiy qiymatlar lokal `.env` faylidan o'qiladi (`.env.example` faqat nomlarni saqlaydi).
